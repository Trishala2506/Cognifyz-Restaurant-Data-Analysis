# Cognifyz Restaurant Data Analysis

This repository contains my **Data Analysis internship work at Cognifyz Technologies**, covering **Level 1 and Level 2** tasks from the provided internship task list.

## Project Overview

The project analyzes restaurant data using Python and focuses on cuisines, cities, price ranges, online delivery, ratings, votes, geographic distribution, and restaurant chains.

## Levels Completed

### Level 1
1. **Top Three Cuisines** – identify the three most common cuisines and calculate their percentages.
2. **City Analysis** – identify the city with the highest number of restaurants and compare average ratings by city.
3. **Price Range Distribution** – visualize price ranges and calculate the percentage in each category.
4. **Online Delivery Analysis** – calculate the percentage of restaurants offering online delivery and compare average ratings.

### Level 2
1. **Restaurant Ratings** – analyze rating distribution, identify the most common rating range, and calculate average votes.
2. **Cuisine Combination** – identify common cuisine entries/combinations and compare their average ratings.
3. **Geographic Analysis** – visualize restaurant locations using latitude and longitude.
4. **Restaurant Chains** – identify repeated restaurant names and analyze outlet count, average rating, and average votes.

## Dataset

The project uses a restaurant dataset containing **9,551 records and 21 columns**, including restaurant name, city, cuisines, price range, online delivery, ratings, votes, latitude, and longitude.

## How to Run

1. Clone or download this repository.
2. Open a notebook from `Level-1` or `Level-2` in Jupyter Notebook or JupyterLab.
3. Make sure the `dataset/Dataset.csv` file is present.
4. Run the notebook cells in order.
